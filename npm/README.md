# @dominionthedev/lean

Install the Lean environment manager through npm:

```bash
npm install -g @dominionthedev/lean
```

Then use the CLI normally:

```bash
lean init
lean create --name dev
lean apply dev
```

The npm package installs the matching Lean release binary for your platform. Go is not required.

Supported platforms:
- Linux amd64
- Linux arm64
- macOS amd64
- macOS arm64
- Windows amd64

For source code and the full documentation, see the main repository.
